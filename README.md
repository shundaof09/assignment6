\## 🎨 UI/UX Improvements



Several intentional design choices were made to create a polished user experience:



\- \*\*Consistent Branding\*\* — A custom logo and cohesive color palette reinforce a professional identity throughout the page

\- \*\*Visual Hierarchy\*\* — Clear headings, card-based layouts, and distinct sections guide the viewer's eye naturally from top to bottom

\- \*\*Readable Typography\*\* — Font sizes and spacing are tuned for comfortable reading across all sections

\- \*\*Accessible Alt Text\*\* — All images include descriptive alt attributes to support screen readers and accessibility standards

\- \*\*Smooth Navigation\*\* — Anchor-linked nav items allow users to jump directly to any section without scrolling manually



\## 📱 Responsiveness



The site is built to look great on any screen size:



\- \*\*Flexible Layout\*\* — CSS is structured so content reflows naturally from desktop to tablet to mobile

\- \*\*Scalable Images\*\* — Banner and profile images resize proportionally without breaking the layout

\- \*\*Touch-Friendly Navigation\*\* — Nav links and call-to-action buttons are sized for easy tapping on mobile devices

\- \*\*Card Stacking\*\* — Feature cards shift from a horizontal row on desktop to a vertical stack on smaller screens



\## 🚀 Deployment Steps



This site is deployed using \*\*GitHub Pages\*\* with the following steps:



1\. Created a new repository on GitHub (`shundaof09/assignment6`)

2\. Added all project files (`index.html`, `styles.css`, images, and `README.md`)

3\. Committed and pushed changes to the `main` branch

4\. Navigated to \*\*Settings → Pages\*\* in the repository

5\. Selected \*\*Source: Deploy from a branch\*\* and chose `main` / `/ (root)`

6\. GitHub Pages automatically built and published the site at the live URL



\## 💭 Reflection



Building this project reinforced several key concepts I've been studying in my Data Science Technology program:



\- \*\*Semantic HTML matters.\*\* Using meaningful tags like `<nav>`, `<section>`, and `<footer>` keeps the code organized and improves accessibility — it's not just about making things look right, but making them work right.

\- \*\*CSS can do a lot with a little.\*\* A single stylesheet handles the entire visual identity of the site, from layout to color to responsiveness. Keeping it in one file made it easier to stay consistent.

\- \*\*Design is communication.\*\* Every choice — the rose-gold-inspired palette, the card layout, the clean spacing — serves a purpose: to make a strong first impression and guide the viewer through the content.

\- \*\*Deployment closes the loop.\*\* Seeing the site live on GitHub Pages made the project feel real. It's one thing to preview in a browser; it's another to share a link that anyone can visit.



This project is a foundation I plan to continue building on as I grow my web development skills.
